# Screenshots

Live screenshots of the Data Dictionary app running in Splunk.

| File | What it shows |
| --- | --- |
| `01-catalog-home.png` | The **catalog** home page inside Splunk: the index/sourcetype table with governance columns (Data Owner, PII Status, Export Classification) and per-row **view (magnifier)** / **edit (pencil)** actions. |
| `02-edit-metadata.png` | The **edit metadata** dialog: per-field dropdowns that suggest existing values, **PII Status as a Yes/No** control, and the **"Apply to"** scope (this sourcetype / all in the index / only the un-set ones). |
| `03-claude-chat.png` | This **Claude Chat** is a quick example of how the MCP tools can be leveraged to save time and to provide Splunk connectivity to non-Splunk users. |
